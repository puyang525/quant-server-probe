# Public community samples

Only sanitized JSON generated by `quant_net_probe.py public` and manually inspected by its contributor is accepted here.

Do not submit complete `probe-*.json` or `probe-*.md` reports, route output, API keys, account information, or wallet information. Read [Data contribution and privacy](../CONTRIBUTING_DATA.md) before submitting.

Provider, datacenter, and plan labels may use any language. Stable JSON fields and ISO country codes make aggregation independent of display language.

The community ranking requires at least three different sample IDs before showing a country/provider/datacenter combination. One file cannot create a public ranking conclusion.
